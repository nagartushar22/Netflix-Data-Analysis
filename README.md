# 🎬 Netflix Movies & TV Shows Data Analysis

## 📌 Project Overview

This project focuses on analyzing Netflix Movies and TV Shows data using Python.

The main objective is to explore Netflix's content library, identify trends, understand content distribution, and generate meaningful business insights through data analysis and visualization.

## 🎯 Project Objectives

* Analyze Movies vs TV Shows distribution.
* Identify countries contributing the most content.
* Explore content release trends.
* Analyze Netflix content ratings.
* Identify the most common genres.
* Generate business recommendations using data.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
